# Конноспортивный клуб и ипподром «Аллюр»

Вариант 22, группа ПР-23. Простое приложение на C# (.NET 8) + Avalonia UI + MySQL.

## Файлы

| Файл | Что внутри |
|---|---|
| `Avalo.csproj` | Один проект Avalonia + MySqlConnector |
| `MainWindow` | Вход, главное окно, переключатель «Клуб / Ипподром», таймер 45 мин |
| `OrderWindow` | Заказ Master-Detail: заголовок + позиции, итог на лету, смена статуса |
| `Db.cs` | Доступ к MySQL (ADO.NET) |
| `Calc.cs` | Формула стоимости, FSM, номер документа, SHA256 |
| `Models.cs` | Классы под таблицы БД |
| `Database/Yes.sql` | Схема БД + демонстрационные данные для phpMyAdmin |

## Запуск

1. phpMyAdmin → создать базу `Yes` → вкладка SQL → загрузить `Database/Yes.sql` → Вперёд
2. При необходимости поправить строку подключения в `Db.cs` (сейчас `root` без пароля)
3. `dotnet run`

**Логины:** `bereitor / bereitor123`, `admin / admin123`, `manager / manager123`

## Правила

- Стоимость: `(минут / 45) × 1500 руб.`, тренер `+1000 руб.`, скидка всадника `discount_rate` (%)
- Лошадь — не более 3 часов тренировок в сутки; лошадь с `is_ready_for_training = false` не назначается
- FSM: `Забронировано → Лошадь оседлана → Тренировка в манеже → Завершена успешно / Отмена по ветпоказаниям`; отмена — с причиной от 10 символов
- Номер документа: `ПР23-КСК-{Год}-{Номер:D5}`
- Экспорт маршрутного листа (.txt/.html) с подписью инструктора и SHA256
- Вход: 3 неверных ввода → блокировка на 10 секунд
