# Конноспортивный клуб и ипподром «Аллюр»

Вариант 22, группа ПР-23, профессиональный модуль ПМ.01.
Приложение на C# (.NET 8) + Avalonia UI (MVVM) + MySQL (EF Core / Pomelo).

## Структура решения

| Проект | Назначение |
|---|---|
| `Allure.Core` | POCO-модели 7 таблиц, `AppDbContext`, сервисы бизнес-логики (расчёт, FSM, SHA256, экспорт, таймер, аутентификация), seed-данные |
| `Allure.Desktop` | Avalonia UI: `LoginWindow`, `MainWindow`, `OrderWindow` (Master-Detail), диалоги, ViewModel-и (CommunityToolkit.Mvvm), DI |
| `Allure.Tests` | xUnit-тесты (ПК 1.4): расчёт, скидки, FSM, `InvalidOperationException`, SHA256, маска номера, блокировка входа, таймер |
| `Database/Yes.sql` | DDL + демонстрационные данные для phpMyAdmin |

## Главная страница: переключатель «Клуб / Ипподром»

Идея из наработок сохранена: в верхней панели — переключатель из двух кнопок.
Дизайн частей похож (общая шапка, таймер, таблицы), но отличается акцент:
- **Клуб Аллюр** (тёплый коричнево-оранжевый): о клубе, заказы с поиском/фильтром/сортировкой, лошади, всадники.
- **Ипподром** (тёмно-зелёный с золотым): расписание занятий и сводка по ипподрому.

## Запуск

1. **База данных.** Откройте phpMyAdmin (`http://localhost/phpmyadmin/`), создайте базу `Yes`,
   вкладка **SQL** → загрузите `Database/Yes.sql` → **Вперёд**.
2. **Строка подключения.** При необходимости правьте `Allure.Desktop/appsettings.json`:
   `server=localhost;database=Yes;uid=root;pwd=;charset=utf8mb4`.
3. **Сборка.** В Visual Studio Code (расширение C# Dev Kit) или терминале:
   ```bash
   dotnet restore YesAiNo.sln
   dotnet run --project Allure.Desktop
   ```
4. **Тесты:** `dotnet test YesAiNo.sln`

## Бизнес-правила (карточка задания № 22)

- **Формула:** `(duration_minutes / 45) × 1500 руб.`; `has_trainer = true` → `+1000 руб./занятие`;
  скидка всадника `discount_rate` (проценты, 0–100).
- **Переутомление:** лошадь — не более 3 часов (180 мин) тренировок в сутки.
- **FSM:** `Забронировано → Лошадь оседлана → Тренировка в манеже → Завершена успешно / Отмена по ветпоказаниям`.
  Пустой заказ нельзя перевести в «Лошадь оседлана»; закрытый заказ нельзя редактировать;
  отмена требует причину ≥ 10 символов; недопустимый переход → `InvalidOperationException`.
- **Допуск:** назначение лошади с `is_ready_for_training = false` заблокировано.
- **Номер документа:** `ПР23-КСК-{Год}-{Номер:D5}`.
- **Экспорт:** маршрутный лист тренировки + акт проверки снаряжения с подписью инструктора;
  цифровая подпись `SHA256([Номер]+[Дата]+[Контрагент]+[Сумма]+[КоличествоПозиций])` в нижней строке (.txt/.html).
- **Таймер:** академический час 45 минут (DispatcherTimer), по окончании — звуковой сигнал.
- **Вход:** маска пароля с переключателем видимости; 3 неверных ввода → блокировка на 10 секунд с обратным отсчётом.
